Roman Trend + Momentum Single / Double

Choose Step 100, 200, or 300. Trend filter uses EMA9 + EMA21 on live ticks. A trade fires only when trend and a 3-move tick pattern agree. Contract duration is editable in ticks.

1. Mode

Roman SinglePick one Step market and run it independently.
Roman DoublePick two different Step markets and run both independently.

2. Account

REAL mode can place trades against your real Deriv Options balance. START remains disabled until every selected Step market is verified for CALL/PUT on the selected account.

3. Strategy

Trend + momentum logic: RISE only when price > EMA9 > EMA21, EMA9 is rising, and the last 3 tick moves are UP. FALL is the exact opposite. Mixed conditions → WAIT. After a trade, that engine must see the signal pattern reset before it can enter again. Choose 1–10 ticks before START; that duration stays fixed for the session. Win resets that market's stake; loss multiplies only that market's stake. Roman Double engines remain independent.
